# ADR 0005 — Advisory-only scope; no setpoint recommendations
Status: accepted (2026-10-09)
Context: industry systems include WOB/RPM/MW recommendation engines; STRATA cannot validate them on public
surface data. Decision: out of scope; the copilot answers such questions with kind `out_of_scope`; copy-lint
enforces wording. "Best parameter window" is descriptive and labelled advisory.
