How lost time is definedNEW v0.2 · PR-1
  1. Each connection, stand and flat-time block is timed from rig-state intervals.
  2. Composite best = 10th percentile per KPI, per hole section, per well.
  3. Lost time = Σ (actual − composite best) where actual > best.
  4. Intervals overlapping a data gap are excluded, and counted on the Trust page.
